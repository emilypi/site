- Routes: `/`, `/posts/`, `/posts/<id>/`, `/notes/`, `/notes/<id>/`, `/tags/`, `/tags/<tag>/`, `/projects/`, `/talks/`, `/about/`, `/404`, `/rss.xml`, `/og/posts/<id>.png`, `/og/notes/<id>.png`, `/og/default.png`, `/sitemap-index.xml`, `/robots.txt`. Directory URLs end with `/`.
- Styling lives in `src/styles/tokens.css` (all colours, fonts, sizes, spacing as CSS custom properties; dark defaults on `:root`, light overrides under `:root[data-theme='light']` and a `prefers-color-scheme: light` media query for first visits), `src/styles/global.css` (reset + utilities `.container`, `.prose`, `.label`, `.hairline`), `src/styles/prose.css` (Markdown typography), `src/styles/fonts.css` (three `@fontsource-variable` imports: Newsreader, Inter, JetBrains Mono). Theme toggle stores `theme` in `localStorage`.
- Components in `src/components/` (Header, Footer, ThemeToggle, PostList, TagList, FormattedDate, TableOfContents, Callout, Figure, Constellation, SectionHeading, ProjectCard, TalkItem), layouts `BaseLayout.astro`, `ArticleLayout.astro`.
- Frontmatter for posts: `title`, `description`, `date`, `updated?`, `tags` (lower-kebab), `draft` (drafts render in `npm run dev`, are excluded from `npm run build`, the feed, and the sitemap), `math` (set true to load KaTeX CSS), `toc`, `lede?`. Notes: same minus `lede`, `toc`. Projects and talks are YAML lists in `src/content/*.yaml` with the fields in `content.config.ts`.
- MDX is enabled: a post can be `.mdx` and import `Callout` and `Figure` from `../../components/`.
- Math: `$…$` inline, `$$…$$` display (remark-math + rehype-katex, rendered at build). Code: fenced blocks with a language; Shiki highlights with light/dark themes; supported languages include haskell, lean4, agda, ocaml, rust, python, typescript, javascript, bash, nix, json, yaml, toml, diff, latex.
- OG images are generated at build by `src/pages/og/…` with satori; the default image is `public/og/default.png` regenerated by `npm run og:default`.
- Deploy: push to `main` → GitHub Actions (`.github/workflows/deploy.yml`) builds and deploys to GitHub Pages; the custom domain is `cohomolo.gy` via `public/CNAME`.
