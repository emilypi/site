## Mission

Build every route except the homepage, the feed, and the OG images, composing exclusively from the existing layouts, components, utility classes, and content helpers. The design system already exists; your job is information architecture and correctness: what goes on each page, in what order, with what empty states, and that every URL in the route table exists in `dist/`.

Author is **Emily Pillmore**. No AI mentions anywhere. Commit as the repo-local git user; no trailers.

## Contracts

### c-components (you CONSUME)

```
BaseLayout      Props { title; description?; ogImage?; type?; math?; publishedTime?; modifiedTime?; noindex? }
ArticleLayout   Props { entry; headings; collection: 'posts'|'notes'; prev?: {title, href}; next?: {title, href} }
PostList        Props { entries; collection; showDescription? }
SectionHeading  Props { label; title?; href?; more? }
TagList         Props { tags; linked? }
FormattedDate   Props { date; format? }
ProjectCard     Props { project }           TalkItem  Props { talk }
TableOfContents Props { headings; maxDepth? }   (ArticleLayout already renders it — do not render twice)
Callout, Figure — used by MDX content, not by you
Utilities: .container, .container--narrow, .prose, .label, .hairline, .visually-hidden, .link-plain
```

### c-routes (you PRODUCE these; all directory URLs end in `/`)

| Route | File | Content |
| --- | --- | --- |
| `/posts/` | `posts/index.astro` | `BaseLayout title="Writing"`. `SectionHeading label="§ writing" title="Writing"` + one-line intro (display italic, muted) taken from a constant in the page. Posts grouped by year (`<h2 class="label">2026</h2>` per group, newest year first) each with `PostList showDescription`. Empty → a single quiet sentence "Nothing here yet." in `.prose`. |
| `/posts/[...id]/` | `posts/[...id].astro` | `getStaticPaths` over `getPublishedPosts()`; `params: { id: post.id }`, props `{ post, prev, next }` where prev = newer, next = older in date order. `const { Content, headings } = await render(post)`. `ArticleLayout entry={post} headings collection="posts" prev next` wrapping `<Content />`. Draft posts get NO route when `import.meta.env.PROD` (already handled by `getPublishedPosts`; assert in log by checking `dist/`). |
| `/notes/` | `notes/index.astro` | Same shape as posts, `§ notes`, no descriptions (`showDescription={false}`), no year grouping unless > 12 notes. |
| `/notes/[...id]/` | `notes/[...id].astro` | As posts, `collection="notes"`. |
| `/tags/` | `tags/index.astro` | `BaseLayout title="Tags"`. `getAllTags()`; render as a flowing list of `<a href="/tags/<tag>/">#tag</a> <span class="label">count</span>` sorted by count desc then name. Hidden tags with zero published entries never appear (helper already does this). |
| `/tags/[tag]/` | `tags/[tag].astro` | `getStaticPaths` from `getAllTags()` → `params: { tag }`. Page title `#tag`; lists posts then notes carrying the tag, each under a `§ writing` / `§ notes` SectionHeading, using `PostList`. Use `slugifyTag` consistently with `TagList` so links resolve. |
| `/projects/` | `projects/index.astro` | `getCollection('projects')`. Group by status in order **active, wip, maintained, archived**; each group `SectionHeading label="§ <status>"`; grid of `ProjectCard` (CSS grid `repeat(auto-fill, minmax(18rem, 1fr))`, gap `var(--space-6)`). Skip empty groups. Short intro line. |
| `/talks/` | `talks/index.astro` | `getCollection('talks')` sorted date desc, grouped by year; `<ol>` of `TalkItem`. |
| `/about/` | `about/index.astro` | `getEntry('about', 'about')` (or `getCollection('about')[0]`); `render()`; `BaseLayout title=entry.data.title description=entry.data.description`; `.container--narrow`; `<h1>` display; `<article class="prose"><Content/></article>`; then a `§ elsewhere` SectionHeading and a list of `SITE.links` (label → href), excluding the `rss` icon entry or including it — your call, be consistent. |
| `/404` | `404.astro` | `BaseLayout title="Not found" noindex`. Centred: `<p class="label">404</p>`, an `<h1>` in display serif "This page has no boundary." (or similar single line with a light cohomology joke — one only), one sentence, links to `/` and `/posts/`. |

Every page passes a `description` to `BaseLayout` (≤ 160 chars). Every page's top element is `.container` or `.container--narrow`; vertical padding `var(--space-12)` top, `var(--space-24)` bottom. Headings on index pages use the display font via a small scoped style or existing classes — read `prose.css` / `global.css` to see what exists before adding scoped CSS.
