## RSS (`src/pages/rss.xml.ts`, helper in `src/lib/feed.ts`)

Use `@astrojs/rss` (already a dependency; check `package.json`). Pattern from docs.astro.build/en/recipes/rss:

```ts
import rss from '@astrojs/rss';
import type { APIContext } from 'astro';
export async function GET(context: APIContext) {
  const items = await feedItems();               // src/lib/feed.ts
  return rss({
    title: SITE.title,
    description: SITE.description,
    site: context.site!,                          // set from astro.config `site`
    items,
    customData: `<language>en</language>`,
    trailingSlash: true,
  });
}
```

`feedItems()`: merge `getPublishedPosts()` (link `/posts/${id}/`) and `getPublishedNotes()` (link `/notes/${id}/`), sort by date desc, take 20, map to `{ title, description, pubDate: date, link, categories: tags, content }`. `content`: render `entry.body` with `markdown-it` (`html: true`, `linkify: true`) then `sanitize-html` with `allowedTags: sanitizeHtml.defaults.allowedTags.concat(['img'])`. For `.mdx` entries (id or `entry.filePath` ending in `.mdx`), MDX component tags will not render: strip lines starting with `import ` and any `<Callout`/`<Figure`… JSX blocks with a conservative regex, or fall back to `description` only when the body contains `</` JSX tags after stripping — log which. Math in the feed stays as raw `$…$` (acceptable; note it). Author field: `SITE.author.email (SITE.author.name)` via `customData` on each item or the `author` property if `@astrojs/rss` supports it — read `node_modules/@astrojs/rss/dist/index.d.ts` for the item schema and use what exists.

## OG images

Fonts: satori needs TTF/OTF/WOFF (not WOFF2). Download OFL-licensed static instances into `src/assets/og/`: Newsreader (regular 400 and italic 400 at an optical size around 24–36, e.g. from `https://github.com/googlefonts/newsreader` releases or `https://github.com/google/fonts/tree/main/ofl/newsreader` — a variable TTF is acceptable if satori renders it; test), Inter Regular/SemiBold (from `https://github.com/rsms/inter/releases` — the static TTFs), JetBrains Mono Regular (from `https://github.com/JetBrains/JetBrainsMono/releases`). Copy each font's licence file (`OFL.txt`) alongside. Keep total font bytes under 1.5 MB (subset by choosing static weights; do not commit whole families). Log every download URL and the licence name.

`src/lib/og.ts`:

```ts
export interface OgInput { title: string; description?: string; date?: Date; tags?: string[]; kind: 'post'|'note'|'site' }
export async function renderOg(input: OgInput): Promise<Uint8Array>   // PNG bytes, 1200×630
```

Implementation: `satori(element, { width: 1200, height: 630, fonts: [...] })` → SVG string → `new Resvg(svg, { fitTo: { mode: 'width', value: 1200 } }).render().asPng()`. Load font files once with `readFileSync` (resolve paths with `new URL('../assets/og/…', import.meta.url)`) and cache the `Buffer`s at module scope. Layout (flex column, padding 64):

- Top row: mono 26px `∂ cohomolo.gy` in `text` colour with the `∂` in `accent` (two spans), right-aligned mono label `§ writing` / `§ note` in `muted`.
- Middle: title in Newsreader 400, 64px (drop to 56 when `title.length > 60`, 48 when > 90), `text` colour, `lineHeight 1.1`, max 3 lines (truncate with `…` when the string is very long — satori does not clip; compute a rough character budget).
- Below title: description in Newsreader italic 30px `muted`, max 2 lines (character-budget truncation).
- Bottom row: mono 22px date (`formatDate(date, 'long')`) in `faint`, tags as `#tag` in `accent-2`; right side an aurora hairline: a 240×2 div with `linear-gradient(90deg, #8fb3ff, #5fe3c9, #c4a6ff)` — satori supports linear-gradient backgrounds.
- Background `#0b0d14` with 14–18 absolutely positioned dots (`borderRadius: 999`, 2–5px, `text` colour at opacity .25–.7, a few in `accent-2`) placed by a seeded LCG from the title's hash so each post's constellation differs but is stable across builds. No external images.
- `kind: 'site'` variant (for the default image): title `SITE.title` at 96px display, description `SITE.author.bio` italic, no date/tags.

Endpoints (`src/pages/og/posts/[...id].png.ts`, same for notes):

```ts
import type { APIRoute, GetStaticPaths } from 'astro';
export const getStaticPaths: GetStaticPaths = async () => (await getPublishedPosts()).map((post) => ({ params: { id: post.id }, props: { post } }));
export const GET: APIRoute = async ({ props }) => {
  const { post } = props as { post: Post };
  const png = await renderOg({ title: post.data.title, description: post.data.description, date: post.data.date, tags: post.data.tags, kind: 'post' });
  return new Response(png, { headers: { 'Content-Type': 'image/png' } });
};
```

Verify the produced path in `dist/` is exactly `dist/og/posts/<id>.png` (no trailing-slash directory). If `trailingSlash: 'always'` turns it into a directory, that is a bug to report — endpoints with file extensions should not get a slash; confirm against the built output and log it.
