## Mission

Give `cohomolo.gy` its look and its bones. You own the CSS design tokens, the global and prose styles, the two layouts, every shared component, and the homepage. The direction (frozen): **an observatory at the edge of the type universe** — a dark void with warm paper text, a cool aurora accent used sparingly, serif display type with true italics for wonder, a humanist sans for reading, a monospace for metadata and code, a static constellation in the masthead, hairline rules, mono section labels (`§ writing`), a `∂` monogram, and a footer that signs off `∂² = 0`. Modern indie-tech-blog restraint, not a landing page. Motion is limited to hover/focus transitions and one gentle twinkle, all disabled under `prefers-reduced-motion`.

Author of everything is **Emily Pillmore**. No file, comment, or commit may mention an AI tool. Commit as the repo-local git user already configured (Emily). No `Co-Authored-By` trailer.

## Typography and prose (`src/styles/prose.css`, class `.prose`)

- `max-width: var(--measure)`, `font-family: var(--font-body)`, `font-size: var(--text-base)`, `line-height: var(--leading-body)`, `text-wrap: pretty` on paragraphs, `hanging-punctuation: first` where supported.
- `h2` display `--text-2xl`, `h3` display `--text-xl`, `h4` body semibold; headings `text-wrap: balance`, `margin-top: 2.2em`. Autolinked heading anchors (`a.heading-anchor` wrapping the heading text, from rehype-autolink-headings `behavior: 'wrap'`) inherit colour, no underline, show a faint `#` before them on hover via `::before`.
- Links: `color: var(--color-accent)`, `text-decoration: underline`, `text-decoration-thickness: 1px`, `text-underline-offset: .16em`, `text-decoration-color: color-mix(in oklab, var(--color-accent) 45%, transparent)`; hover → full accent. External links get no icon.
- `em` in display italic? No — keep body italic. `strong` weight 600.
- `blockquote`: left `2px solid var(--color-accent-3)`, `padding-left: var(--space-4)`, display italic `--text-lg`, muted.
- Inline `code`: mono `--text-sm`, `background: var(--color-bg-elevated)`, `padding: .1em .35em`, `border-radius: var(--radius-sm)`, `border: 1px solid var(--color-rule)`.
- `pre.astro-code`: `background: var(--color-bg-elevated)`, `border: 1px solid var(--color-rule)`, `border-radius: var(--radius-md)`, `padding: var(--space-4) var(--space-6)`, `overflow-x: auto`, mono `--text-sm`, `line-height: 1.55`, `tab-size: 2`; when `data-language` is present show it as a top-right mono label via `::before` (`content: attr(data-language)`). Full-bleed slightly beyond the measure on ≥ 900px (`margin-inline: calc(var(--space-6) * -1)`) is allowed but not required.
- `.katex-display`: `overflow-x: auto; overflow-y: hidden; padding: .25em 0`. `.katex` font-size `1.05em`.
- `table`: full width, `border-collapse`, hairline rows, `th` mono label; wrap in `overflow-x: auto` via `.prose table { display: block; overflow-x: auto }` only if it does not break layout; otherwise `figure`-wrap guidance for p7.
- `figure` centred, `figcaption` label style; `img { max-width: 100%; height: auto; border-radius: var(--radius-md) }`.
- Footnotes: `section.footnotes` (or `.footnotes`) top hairline, `--text-sm`, muted; `a[data-footnote-ref]` mono superscript; back-references `↩`.
- `hr`: `border: 0; border-top: 1px solid var(--color-rule); margin: var(--space-12) auto; width: 33%`.
- `ul` bullets as `–`? Use a custom marker: `::marker { color: var(--color-text-faint) }`. Task lists render checkboxes disabled and aligned.
